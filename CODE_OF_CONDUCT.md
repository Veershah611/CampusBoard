# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

## Our pledge

We want CampusBoard to be a welcoming, harassment-free community for everyone, regardless of age, background, gender identity, ability, experience level, or any other personal characteristic.

## Expected behaviour

- Be respectful and constructive in issues, pull requests, and reviews.
- Give credit to others' work and ideas.
- Accept feedback gracefully and focus on what is best for the project.

## Unacceptable behaviour

- Harassment, insults, or personal attacks.
- Publishing others' private information.
- Submitting someone else's work as your own (plagiarism).

## Enforcement

Report problems to the maintainers at **[maintainer e-mail]**. Maintainers may remove comments or contributions that break this code and may temporarily or permanently ban repeat offenders.
